# MU1161 / 791 AID 12.3

- Firmware gate: `/ifs/lsd.jxe` = **55,830,309 bytes**
- Display: **40 fps declaration, turn card centered at the top, car marker centered below**
- Steering controls: short press zoom; long press map switch
- Profile core: `payload/profiles/MU1161/791/core.so` (same file as MU1102/791 and MU1367/791)
- Tested in a VW Passat B8 2018, Discover Pro 5NA035045B, hardware H54, iPhone over USB

This is a standalone CarPlay Maps VC file set, not a complete toolbox. From this directory on the MMX shell, run `/bin/ksh ./run-install.sh`. The installer performs the exact firmware/profile check again and does not reboot automatically.
