# V2.1 community acknowledgements / 社区特别致谢

## Special thanks to olli991 / 重点感谢 olli991

**[olli991](https://github.com/olli991)** provided many valuable development ideas,
practical suggestions and SEAT testing feedback that helped guide this update.
His help went beyond identifying symptoms: the comparisons with the factory
navigation views, restart behaviour and map presentation helped us investigate
the differences between SEAT and the existing Volkswagen implementation.

**特别感谢 [olli991](https://github.com/olli991)** 提供了大量开发思路、实际建议和
西雅特测试反馈。对原厂导航画面、重启后设置生效情况及地图显示效果的对比，
帮助我们定位西雅特与既有大众实现之间的差异，并改进本次更新的方向。

感谢 [octacon84](https://github.com/octacon84) 提交基于 MU1440 适配的 MU1447
