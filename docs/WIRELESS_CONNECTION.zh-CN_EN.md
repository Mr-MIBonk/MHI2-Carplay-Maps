# 无线 CarPlay 连接方法 / Wireless CarPlay connection

## 中文连接步骤

首次使用需要手动完成 **蓝牙配对和车机 Wi-Fi 连接**。只打开“无线 CarPlay”开关，或只连接蓝牙，不等于无线 CarPlay 会话已经建立。

1. 安装成功并完整重启车机。先拔下 iPhone 的 USB 线，保持手机蓝牙和 Wi-Fi 开启。
2. 在车机“手机连接设置”中开启 **无线 CarPlay**。打开原车 WLAN／热点设置，确认车机热点已开启，并查看这台车机自己的网络名称和密码。
3. 在 iPhone 的“设置 → 蓝牙”中选择这台车机，手动完成配对，并确认手机和车机显示的配对请求。
4. 在 iPhone 的“设置 → Wi-Fi”中选择 **这台车机的 Wi-Fi 热点**，输入车机页面显示的密码并加入。不是让车机去连接手机的个人热点，也不是连接家里或店里的上网 Wi-Fi。
5. 蓝牙配对与车机 Wi-Fi 均完成后，无线 CarPlay 才能启动。如果没有自动进入，回到车机 App-Connect，选择当前 iPhone 的 CarPlay 连接。
6. 先确认中控的画面、声音和触控正常，再打开导航并检查仪表地图；随后分别检查镜像、导航卡片和方向盘地图缩放。

车机热点如果没有外部网络，手机可能显示“无互联网连接”；这条提示本身不代表本地无线 CarPlay 连接失败。不要因此把手机切回另一个 Wi-Fi。后续重连仍需蓝牙、Wi-Fi 和车机热点可用；不能把一次自动重连成功当作所有机型都无需手动连接。

连接转圈或未启动时，先核对：连接的是否为当前车机热点、密码是否正确、无线 CarPlay 开关和热点是否已开启、USB 是否仍插着。蓝牙已连接但 Wi-Fi 未加入时，先补齐 Wi-Fi 连接，不要反复重装。首次使用与新增机型仍需按安装说明完成实机验收。

## Connection steps in English

For first use, **manually pair Bluetooth and join the head unit's Wi-Fi network**. Enabling the Wireless CarPlay switch, or connecting Bluetooth alone, does not establish the complete wireless session.

1. Finish installation and fully restart the head unit. Unplug the iPhone USB cable and leave Bluetooth and Wi-Fi enabled on the phone.
2. Enable **Wireless CarPlay** in the head unit's phone-connection settings. Open its native WLAN/hotspot settings, enable the head-unit hotspot and check this unit's own network name and password.
3. On the iPhone, open **Settings → Bluetooth**, select the head unit and complete pairing manually. Confirm the pairing requests shown on the phone and head unit.
4. Open **Settings → Wi-Fi** on the iPhone and join **the head unit's Wi-Fi hotspot**, using the password displayed by that unit. This does not mean connecting the head unit to the iPhone's Personal Hotspot or joining a home/shop internet Wi-Fi network.
5. Wireless CarPlay can start after both Bluetooth pairing and the head-unit Wi-Fi connection are complete. If it does not open automatically, select the current iPhone's CarPlay connection in App-Connect.
6. Check main-screen video, sound and touch first. Then start navigation and check the cluster map, followed by mirroring, navigation cards and steering-wheel map zoom separately.

A head-unit hotspot without an external uplink may show **No Internet Connection** on the phone. That warning alone does not establish a local CarPlay failure; do not switch the phone to another Wi-Fi for that reason. Later reconnection still requires Bluetooth, Wi-Fi and the head-unit hotspot to be available. Automatic reconnection on one tested combination is not a universal first-use guarantee.

If connection spins or does not start, check the selected hotspot and password, the Wireless CarPlay and hotspot switches, and whether USB is still attached. If Bluetooth is connected but Wi-Fi is not, finish joining Wi-Fi instead of reinstalling repeatedly. Complete the installation guide's physical acceptance checks, especially on newly added firmware targets.
