# Wireless CarPlay Maps V3.0

**试验预发布 / Experimental prerelease**

让支持的 MHI2 车机使用无线 CarPlay，将手机地图映射到仪表，让仪表也显示地图画面。V3.0 同时保留地图、镜像、导航卡片与方向盘地图缩放，采用独立 SD／绿色菜单安装，不要求完整工具箱。

Use wireless CarPlay on supported MHI2 head units and display the phone map on the instrument cluster. V3.0 also provides mirroring, navigation cards and steering-wheel map zoom. Installation uses a dedicated SD/green-menu package, not the full toolbox.

## 中文安装步骤

1. 核对支持的精确固件及仪表，准备完整系统备份与恢复通路。不要跳过“不支持”提示。
2. 车辆停稳，持续稳定供电，完全断开手机的 USB 与无线 CarPlay。工程／绿色菜单应已可用；本包不代替开启工程模式。
3. 下载 V3.0 Standalone ZIP，按 `SHA256SUMS.txt` 校验后解压。
4. 把 `SD_ROOT` 内所有内容复制到 SD 卡根目录，保持目录完整，不多套一层文件夹。
5. 在原车软件更新入口选择 SD 介质，先完成独立管理入口注册。此步不是刷完整固件，也不等于功能已经安装。
6. 进入绿色菜单 **Wireless CarPlay Maps V3.0**：790 选择 AID 10.5 项，791 选择 AID 12.3 项，仍以精确固件核对结果为准。
7. 等待 `WMAPS_FEATURE_COMMIT_OK` 及全部校验成功，再手动完整重启，之后连接手机验收。失败先保存日志，不反复安装、不删除备份。

已安装前代版本时，使用新的完整 V3.0 介质，先选 `Update this management entry only`，再选 `Update installed Wireless CarPlay Maps`。恢复使用 `Restore saved first baseline - keep this entry`；需要移除入口时选择 `Restore baseline and remove this entry`。首次基线可能是安装前的旧公开版本，不一定是原厂。不要再运行旧 SD 的卸载脚本。

## Installation in English

1. Check the exact supported firmware and cluster. Keep a full system backup and recovery path. Never bypass an unsupported-target refusal.
2. Park safely, maintain reliable power and disconnect both USB and wireless CarPlay. Engineering/green-menu access must already be available; this package does not enable it.
3. Download the V3.0 Standalone ZIP, verify it with `SHA256SUMS.txt`, then extract it.
4. Copy everything inside `SD_ROOT` to the card root without an extra outer folder. Preserve all directories and files.
5. Select the SD medium in the native software-update interface and register the independent manager first. This is not a full firmware flash or completion of feature installation.
6. Open **Wireless CarPlay Maps V3.0** in the green menu. Choose AID 10.5 for 790 or AID 12.3 for 791, subject to the exact firmware gate.
7. Wait for `WMAPS_FEATURE_COMMIT_OK` and all checks to succeed. Fully reboot manually before connecting the phone. Preserve logs on failure; do not repeatedly reinstall or delete backups.

To upgrade a predecessor, use the new complete V3.0 media and choose `Update this management entry only` before `Update installed Wireless CarPlay Maps`. Restore with `Restore saved first baseline - keep this entry`; use `Restore baseline and remove this entry` to restore and remove the manager. The first baseline may be an older public installation rather than factory state. Do not use an old SD uninstaller.

## 适配与功能范围 / Compatibility and scope

- **MU1102：**本版提供实际无线服务，支持列明的 790／791 精确配置。Actual wireless service for the listed exact 790/791 configurations.
- **MU1367、Škoda MU1440／MU1433、SEAT MU1447：**仍仅有线，仪表限制以首页表格及安装器精确核对为准。Wired-only; exact cluster/firmware limits remain enforced.
- **未列出平台：**台湾其他固件、欧洲及 Audi MHI2／MHI2Q 的进一步适配继续进行，不因名称相似推定兼容。Unlisted targets are still pending; similar names do not establish compatibility.
- **手机配置：**只保留 iPhone 17 Pro Max；790／791 保留必要的独立硬件适配。Only the iPhone 17 Pro Max phone profile is offered.

本包保留地图、镜像、导航卡片和地图缩放，不安装独立音乐／封面／导航文字映射、仪表启动画面或迎宾／离车声音。This lean package retains map, mirror, cards and zoom; it does not install separate song/artwork/navigation-text mapping, cluster startup presentations or welcome/exit sounds.

## 菜单仪表识别修订 / Menu cluster identification

发布核对发现旧菜单可能把产品版本文件误当成仪表型号。V3.0 改为优先读取独立的 `PROFILE` 并核对确认值，保留真实旧仪表标识的兼容，拒绝未知和冲突配置；九十二项识别检查通过。只替换 MU1102 菜单中的对应分类辅助类，其他类及原生接收、地图、缩放程序不变。

An older menu could mistake a product version for cluster identity. V3.0 prioritizes the dedicated `PROFILE`, checks confirmed identity, retains genuine legacy identifiers and rejects unknown/conflicting inputs. Ninety-two identification cases pass. Only the relevant MU1102 menu helper class changes; other members and native receiver/map/zoom programs remain unchanged.

## 验证与已知边界 / Validation and known limits

本次重新检查 V3.0 当前安装流程、历史公开版升级及前一个已发布无线包到 V3.0 的迁移；归档重新计算清单、回读并解压核对。具体结果见随源码验证记录。离线测试不等于全部真实手机、仪表、触屏、网络或长期实车验收。

V3.0 installation, historical upgrades and migration from the published wireless predecessor are rechecked, with regenerated manifests and archive readback/extraction verification. See the supplied validation records. Offline tests are not complete phone, cluster, touch, radio or long-term vehicle acceptance.

个例首次无线断连、790 卡片位置、实际使用流畅度及自定义网络策略共存仍需实机复核。Home 后后台画面暂停、静态页面返回延迟与倒车影像到仪表仍暂缓；USB 未拔除时，从主动断开的有线再次选择无线仍有限制。

Individual first-connection drops, 790 card placement, real-use smoothness and custom network-policy coexistence still require hardware checks. Background display pause after Home, delayed return from static pages and reverse-camera-to-cluster work remain deferred. A wired-to-wireless reselection limitation remains when USB is still connected.
