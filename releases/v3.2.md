## V3.2 解决什么 / Changes

1. 管理入口按完整组件清单核对并作为整体替换，补齐事务恢复助手，避免新 SD 读取旧入口时缺依赖。
2. 保留旧入口的介质发现兼容；安装请求衔接到完整新版管理组件，再执行正确的功能安装。
3. 增加入口更新的独立恢复阶段与稳定互斥；保留首次基线，核对之后处理可恢复的中断。外部改动、损坏备份和不明旧状态继续拒绝覆盖。
4. 修正原厂软件更新收尾、完整 MMX 节点路径与精简系统工具兼容；注册成功后开启并保存开发者／绿色菜单开关。
5. 暂存并验证完整输入后再写功能文件；只有整套提交完成才显示最终成功，不把中间地图阶段当作完成。
6. 按最终文件重新核对元信息、目录校验、包内清单与下载 SHA-256。SD 根目录仅保留 `metainfo2.txt`、`install/`、`carplay/`。

V3.2 checks and replaces the manager as a complete bundle, adds legacy-entry handoff and recoverable manager replacement, preserves the first baseline, corrects native-update finalization/node/tool compatibility, enables saved green-menu access and confirms full feature commit only after complete staging/verification. Metadata, directory checksums and manifests are checked against final files. Unrelated system settings and runtime business payloads are not rewritten by this installation revision.

## SD 安装 / SD installation

```text
SD root
├─ metainfo2.txt
├─ install/
│  ├─ CONTENTS.sha256
│  ├─ MANAGER.sha256
│  ├─ esd/
│  └─ scripts/final/
└─ carplay/payload/
   ├─ common/
   ├─ profiles/
   └─ wireless/
```

把 ZIP 中 **`SD_ROOT` 内的全部内容**复制到卡根，不要多套一层文件夹。车辆停稳、稳定供电、完全断开 CarPlay：先用原车软件更新注册 V3.2 管理入口，再进入 `wireless-carplay-maps` 绿色菜单安装匹配仪表。790 选 AID 10.5，791 选 AID 12.3，但不能越过固件检查。

Copy **the contents inside `SD_ROOT`** directly to SD root. Park safely, maintain power and disconnect CarPlay. Register V3.2 through native SD software update, then install the matching profile in the dedicated green menu: AID 10.5 for 790, AID 12.3 for 791, subject to exact-firmware checks.

系统软件更新一项显示 `OK` 只代表管理入口成功。功能安装最终需要看到 **`WMAPS_FEATURE_COMMIT_OK`** 和 **`WMAPS_STANDALONE_FEATURE_OK`**。中途不要拔卡；返回菜单后再取卡，按流程完成重启，之后再连接手机测试。错误时保留截图与恢复材料，不反复强刷或删除备份。

The native-update `OK` confirms manager registration only. Final feature success requires both markers above. Keep SD inserted during installation; return to the menu before removing it or restarting. Preserve screenshots and recovery material on failure.

**首次无线连接：先手动配对蓝牙，再让 iPhone 加入车机自身 Wi-Fi 热点，两项连接完成后无线 CarPlay 才会启动。** 不是手机个人热点，也不是仅打开无线开关。

**First manually pair Bluetooth, then join the head unit's own Wi-Fi hotspot from iPhone. Both are required before wireless CarPlay starts.** Do not substitute Personal Hotspot or only enable a switch.

## 已知问题 / Known issue

VW 返回原厂入口的图标下方可能不显示 `Volkswagen` 文字。该显示问题留待 V3.3／V3.4 处理，不修改这份已测通过的 V3.2 安装包。其他长期运行、不同手机／仪表及原车功能仍需分项验收。

The VW return icon may have no `Volkswagen` caption. This is deferred to V3.3/V3.4 and is not changed in the user-tested V3.2 installer. Long-duration behavior, other phone/cluster combinations and factory functions still require separate acceptance.
